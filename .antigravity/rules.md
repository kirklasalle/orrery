# Antigravity v2 Environment Rules & Agent Behavioral Constraints

## Layout Configuration
- **IDE Interface Layout**: Classic IDE layout
- **Primary Agent Roles**: Perception (System 1), Deliberation (System 2), Synthesis (Corpus Callosum / Aggregator)

---

## Agent Role Definitions

### 1. Perception Agent (Right Hemisphere / System 1)
- **Primary Responsibility**: Environmental sensing, broad context gathering, candidate hypothesis generation, and signal extraction.
- **Operating Parameters**: High temperature / flexible context exploration.
- **Behavioral Constraints**:
  - Focus on non-linear pattern recognition, raw input normalization, and generating multiple plausible execution hypotheses.
  - Output structured Perception Artifacts (`PerceptionContext`) detailing extracted signals, environmental variables, and initial candidate strategies.
  - Do NOT perform strict constraint validation or final action execution directly.

### 2. Deliberation Agent (Left Hemisphere / System 2)
- **Primary Responsibility**: Constraint checking, formal verification, truth table validation, and risk analysis.
- **Operating Parameters**: Low temperature / deterministic logic execution.
- **Behavioral Constraints**:
  - Evaluate hypotheses generated by System 1 against system rules, security policies, state constraints, and formal criteria.
  - Construct detailed Critique Tables (`CritiqueTable`) scoring each proposed path on feasibility, safety, efficiency, and policy compliance.
  - Fail candidate paths that violate invariants or lack necessary state prerequisites.

### 3. Synthesis Agent (Corpus Callosum / Aggregator)
- **Primary Responsibility**: Conflict resolution, hypothesis selection, plan unification, and final state synthesis.
- **Operating Parameters**: Medium temperature / balanced synthesis.
- **Behavioral Constraints**:
  - Reconcile candidate hypotheses from System 1 with critique feedback from System 2.
  - Synthesize a single verified, stateful execution plan.
  - Trigger checkpointing prior to dispatching actions to execution adapters.

---

## Cycle Interface Constraints

1. **State Isolation**: Every cognitive cycle step must operate on immutable state snapshots (`StateContext`) or explicitly registered checkpoints.
2. **Backtracking Invariant**: If a micro-cycle reflection score falls below threshold $\theta_{\text{critique}} = 0.70$, the execution state MUST roll back to the nearest checkpoint before re-planning.
3. **Multi-Tier Delegation**: Higher-tier cycles (Meta/Macro) MUST delegate execution steps to lower-tier cycles (Meso/Micro) and wait for verified execution receipts before advancing.
