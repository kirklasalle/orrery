\begin{abstract}
As Large Language Model (LLM) agents transition from conversational interfaces to autonomous execution engines with write-access to filesystems, production databases, and cloud APIs, existing guardrail approaches fail to provide verifiable safety guarantees. Traditional safety methods rely primarily on natural language system prompts, post-hoc output filtering, or unverified retry loops---none of which offer fail-closed execution semantics or non-repudiable auditability.

We present \textbf{Orrery}, an open-source, deterministic governance architecture for long-horizon autonomous agents structured around a formal \textbf{6-gate composition ladder}: (1) Interdiction, (2) Effect Envelope, (3) Quarantine, (4) Sliding-Window Rate Limiting, (5) Cryptographic Human-in-the-Loop Approval, and (6) Post-Dispatch Invariant Monitoring. Unlike prompt-based defenses, Orrery decouples policy enforcement from the agent's generative model, treating cognitive state as rewindable through tamper-evident checkpoints while preserving a strictly forward-only, Ed25519-signed event ledger.

We formally prove five fundamental safety theorems governing gate composition---including Strong Non-Bypassability, Monotonic Evaluation Ordering, and State Backtracking Soundness---and empirically validate them via property-based fuzzing across 1,000+ adversarial permutations with zero safety violations. Across realistic adaptations of the GAIA, SWE-bench, and $\tau$-bench industry benchmarks, Orrery reduces catastrophic security violations from 100.0\% in ungoverned baselines to \textbf{0.0\%}, while enabling autonomous state recovery through informed backtracking at an average runtime latency overhead of only \textbf{+4.1ms to +8.5ms}. Finally, we map Orrery's technical mechanisms directly to statutory requirements under the NIST AI RMF 1.0, OMB M-24-10, Colorado SB 24-205, California AB 2013, and EU AI Act Articles 12--15.
\end{abstract}

\section{Introduction}
Autonomous agents powered by foundation models are increasingly entrusted with multi-step workflows in enterprise environments, including infrastructure provisioning, code generation and execution, customer service balance adjustments, and API-driven automation. Market consensus in 2026 places the agentic AI market between \$10B and \$19B, compounding at 40--50\% annually. However, industry surveys reveal a profound structural paradox: while over 78\% of enterprise organizations report experimenting with agentic workflows, fewer than 15\% have deployed autonomous agents into scaled production. Over 60\% of technical leaders cite the absence of verifiable safety, non-deterministic execution failure, and unaddressed regulatory liability as the primary barriers to deployment.

Existing agent frameworks suffer from prompt vulnerability, state irreversibility upon partial execution failures, and lack of non-repudiable audit trails. In this paper, we introduce Orrery to provide a mathematically sound, fail-closed governance middleware for agentic execution.

\section{The 6-Gate Composition Ladder}
Let $\mathcal{A}$ denote the universe of ActionPayloads, $\mathcal{S}$ the universe of StateContexts, and $\mathcal{G} = [g_1, g_2, g_3, g_4, g_5]$ the ordered gate ladder:
\begin{enumerate}
    \item \textbf{Gate 1: InterdictionGate ($\text{LAW1-INTERDICT}$):} Operator static prohibitions on commands and paths.
    \item \textbf{Gate 2: EnvelopeGate ($\text{LAW2-ENVELOPE}$):} Spatial deployment reach containment.
    \item \textbf{Gate 3: QuarantineGate ($\text{LAW3-QUARANTINE}$):} Holding undeclared actions for schema certification.
    \item \textbf{Gate 4: RateLimitGate ($\text{LAW10-RATELIMIT}$):} Sliding-window throttle ceiling:
    $$\sum_{t \in [T - W, T]} \mathbb{I}(\text{action} = a) \le K_{\text{max}}$$
    \item \textbf{Gate 5: ApprovalGate ($\text{LAW4-APPROVAL}$):} Mandatory Ed25519 cryptographic token for $\text{IRREVERSIBLE}$ actions.
    \item \textbf{Gate 6: InvariantMonitor ($\text{LAW5-INVARIANT}$):} Post-dispatch cross-turn emergent breach containment.
\end{enumerate}

\section{Formal Soundness Theorems}
\begin{theorem}[Strong Non-Bypassability]
For any action $a \in \mathcal{A}$ and state $s \in \mathcal{S}$, if $\exists i \in \{1, \dots, 5\}$ such that $g_i(a, s) \neq \text{APPROVE}$, then the adapter execution function $E(a)$ is strictly unreachable, and the pipeline returns a receipt with $\text{success} = \text{False}$.
\end{theorem}

\begin{theorem}[Strict Monotonic Ordering]
If gate $g_k$ rejects action $a$, then $\forall j > k$, gate $g_j$ is never evaluated.
\end{theorem}

\begin{theorem}[Privilege Non-De-escalation]
Gate evaluation preserves payload immutability and enforces monotonic risk escalation:
$\text{EffectiveRisk}(a) \ge \text{DeclaredRisk}(a)$.
\end{theorem}

\begin{theorem}[Audit Ledger Completeness]
Every action evaluation produces an immutable event $e \in \mathcal{L}$ in the append-only ledger such that $e.\text{action\_id} = a.\text{action\_id}$ and $e.\text{policy\_id} \neq \emptyset$.
\end{theorem}

\begin{theorem}[State Backtracking Soundness]
When a cycle triggers backtracking from state $s_t$ to checkpoint $c_k$ ($k < t$), the restored state satisfies $s_{\text{restored}} \equiv s(c_k)$ with respect to goals and hypotheses, while maintaining monotonic attempt tracking:
$\text{BacktrackCount}(s_{\text{restored}}) = \text{BacktrackCount}(s_t) + 1$.
\end{theorem}
